# Steve 的小站 · HomePage

Steve 的个人主页源码，使用静态 HTML/CSS 构建，并通过 GitHub Pages 发布。

让安卓保持开放！访问：[![Keep Android Open](https://shields.io)](https://keepandroidopen.org)

## 网站地址

- 个人主页：<https://steve0309.dpdns.org/>
- GitHub 仓库：<https://github.com/SteveYuanlong9321/HomePage>

## 页面内容

- `index.html`：个人主页与项目入口
- `style.css`：网站公共样式
- `author.html`：作者社交主页
- `coolapk.html`：酷安主页与二维码页面
- `android-open.html`：Android 开发者验证与 APK 安装政策说明页
- `assets/coolapk-qr.svg`：酷安二维码资源

## 部署说明

此仓库使用 GitHub Pages 发布，发布来源为 `main` 分支的根目录。更新网站文件并提交到 `main` 后，GitHub Pages 会自动构建和部署。

自定义域名 `steve0309.dpdns.org` 专用于个人主页；AppSpace 与 Tickets 使用各自的 GitHub Pages 项目地址。
